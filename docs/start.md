# 작업 시작

프로젝트 문서의 공통 진입점은 [README.md](README.md)입니다.

1. [현재 상태](current-state.md)에서 이번 범위와 미해결 과제를 확인합니다.
2. 명령을 실행한다면 [환경 구분](core/environment-guide.md)에서 실행 위치·앱·DB·영향을 확인합니다.
3. README의 분야별 목차에서 해당 작업의 계약과 절차를 읽습니다.
4. 변경 범위에 맞게 검증하고 [작업 현황](phase-plan.md)을 갱신합니다.

과거 안정화 문서의 기능 동결 지시나 `KEEP_OBSERVING` 관측값을 현재 리팩토링의 일괄 금지 규칙으로 사용하지 않습니다. 운영 데이터 변경과 외부 호출은 별도의 명시된 작업 범위에 한정합니다.
