# Frontend Authenticated User Flow Runbook

문서군 진입점: [frontend-qa-docs-index.md](./frontend-qa-docs-index.md)

## 목적

이 문서는 로그인 사용자가 메인 진입 뒤 실제로 밟는 가장 짧은 핵심 흐름을 고정합니다.

현재 기본 흐름은 아래입니다.

1. `/login` 로그인
2. 메인 진입
3. `처음 시작 가이드` 배너 확인
4. `추천 품질 우선 개선` 또는 `추천 정확도 보강` CTA 확인
5. `/guide` 또는 `/mypage?tab=...` 로 이어짐

즉 “로그인 -> 메인 보강 안내 -> 가이드/마이페이지” 경계를 한 번에 보는 runbook 입니다.

## 현재 기준선

로그인 직후 메인에서는 아래가 동시에 끊기지 않아야 합니다.

- 우선순위/표준코드 상태에 맞는 추천 nudge toast
- `처음 시작 가이드` 배너
- 메인 추천 보강 CTA

현재 high-signal 경계는 아래입니다.

- 우선순위가 없으면 `맞춤 재추천 → /mypage?tab=1`
- 표준코드 공백이 크면 `맞춤 재추천 → /mypage?tab=0`
- 첫 로그인/가입 직후면 `이용가이드 보기 → /guide`

## Playwright 기준선

관련 smoke:

- `메인 재추천 CTA는 우선순위가 없으면 마이페이지 우선순위 탭으로 이동한다`
- `메인 개인 맞춤 재추천 CTA는 표준코드 공백이 크면 마이페이지 내 정보 탭으로 이동한다`
- `로그인 직후 메인에서는 우선순위와 표준코드 공백에 대한 추천 nudge를 한 번 보여준다`
- `로그인 사용자 핵심 흐름은 메인에서 가이드와 추천 보강으로 이어진다`

실행:

```bash
cd frontend
PLAYWRIGHT_GREP='메인 재추천 CTA는 우선순위가 없으면 마이페이지 우선순위 탭으로 이동한다|메인 개인 맞춤 재추천 CTA는 표준코드 공백이 크면 마이페이지 내 정보 탭으로 이동한다|로그인 직후 메인에서는 우선순위와 표준코드 공백에 대한 추천 nudge를 한 번 보여준다|로그인 사용자 핵심 흐름은 메인에서 가이드와 추천 보강으로 이어진다' npm run test:e2e
```

## 해석 기준

- 로그인 직후 guide 배너가 사라지면 onboarding 회귀입니다.
- `맞춤 재추천` CTA가 잘못된 탭으로 가면 recommendation improvement UX 회귀입니다.
- 메인에서 `/guide` 와 `/mypage` 둘 다 이어지지 않으면 로그인 사용자 핵심 흐름 회귀로 봅니다.
