# Frontend QA Checklist

문서군 진입점: [frontend-qa-docs-index.md](./frontend-qa-docs-index.md)

## 목적

이 문서는 브라우저 관점에서 실제 사용자 흐름을 수동 검증할 때 쓰는 runbook입니다.

## 사전 조건

- frontend dev/prod local 실행 가능 상태
- backend local API 정상 기동
- 일반 사용자 1명
- 필요 시 admin 권한이 있는 사용자 1명
- 브라우저 devtools network 확인 가능

## 1. 공개 탐색

### 홈

- `/` 진입
- 정책 카드 목록 로드 확인
- 추천 모드 토글/안내 메시지 확인

기대 결과:

- 초기 진입에서 깨진 레이아웃, 무한 spinner, 콘솔 에러가 없어야 함

### 정책 목록

- `/policies` 진입
- 카테고리 변경
- 지역 필터 변경
- 검색 실행
- 페이지네이션 이동

기대 결과:

- 각 조작 후 목록이 갱신됨
- 빈 결과여도 에러 대신 empty state 또는 0건 상태가 보여야 함

## 2. 뒤로가기 / 재진입

### 목록 -> 상세 -> 뒤로가기

- `MainPage` 또는 `PoliciesPage` 에서 정책 상세 진입
- 상세 페이지의 `뒤로가기` 버튼 클릭
- 브라우저 back 버튼도 별도로 확인

기대 결과:

- 이전 화면으로 복귀
- 복귀 직후 브라우저 오류/blank page 없음

추가 확인:

- `PoliciesPage` 에서 검색/필터/페이지 상태가 기대대로 유지되는지 확인
- 유지되지 않으면 기능 실패라기보다 현 구조상 제한인지 별도 기록

### 마이페이지 북마크 -> 상세 -> 뒤로가기

- `/mypage` 북마크 탭 진입
- 북마크 상세 진입
- 뒤로가기

기대 결과:

- 다시 북마크 탭으로 복귀

## 3. 로그인 / 리다이렉트

### 로그인 필요 경로

- 비로그인 상태에서 `/chat` 직접 접근

기대 결과:

- `/login` 으로 이동
- 로그인 화면 안내 메시지 표시

### 로그인 후 원래 위치 복귀

- 위 상태에서 로그인 수행

기대 결과:

- 다시 `/chat` 으로 복귀

## 4. 세션 만료

### 만료 후 자동 로그인 화면 이동

- 로그인된 상태에서 access token/refresh token 만료 또는 무효 상태를 재현
- 보호 API 호출 유도

기대 결과:

- refresh 1회 시도 후 실패하면 `/login` 이동
- “로그인 상태가 만료되어 다시 로그인해야 합니다.” 안내 확인

추가 확인:

- local token 제거
- 무한 refresh loop 없음

## 5. 북마크

### 메인/목록/상세 일관성

- 메인 카드에서 북마크 on/off
- 정책 목록 카드에서 같은 정책 북마크 상태 확인
- 정책 상세에서 같은 정책 북마크 상태 확인
- 마이페이지 북마크 목록 확인

기대 결과:

- 같은 정책에 대해 화면 간 상태가 크게 어긋나지 않아야 함
- 토글 실패 시 toast가 떠야 함

## 6. 마이페이지

### 프로필

- `/mypage` 진입
- 프로필 조회 확인
- 일부 필드 수정 후 저장

기대 결과:

- 저장 성공 toast
- 새로고침 후 반영 유지

### 우선순위

- 우선순위 추가/삭제/순서 변경
- 저장

기대 결과:

- 저장 성공
- 새로 진입 후 반영 유지

### 비밀번호 변경

- 현재 비밀번호/새 비밀번호 입력 후 변경

기대 결과:

- 성공 시 재로그인 요구 흐름 진입

### 회원탈퇴

- 탈퇴 modal 진입
- 잘못된 비밀번호 / 올바른 비밀번호 각각 확인

기대 결과:

- 잘못된 비밀번호면 실패 안내
- 정상 탈퇴면 로그아웃 후 홈 또는 지정 경로 이동

## 7. 추천

### 추천 조회

- 로그인 후 메인 추천 모드 진입
- 추천 목록 로드 확인

### 추천 새로고침

- 추천 refresh 버튼 실행

기대 결과:

- 중복 클릭 방지 또는 loading 상태 확인
- 성공 시 갱신 toast
- 실패 시 에러 toast

### 추천 -> 상세 -> 복귀

- 추천 카드 상세 진입
- 뒤로가기

기대 결과:

- 추천 화면 복귀

## 8. 챗봇

### 세션 생성 / 메시지 전송 / 삭제

- `/chat` 진입
- 세션 생성
- 메시지 전송
- 세션 목록 재확인
- 세션 삭제

기대 결과:

- 세션/메시지 CRUD가 끊기지 않아야 함
- 메시지 전송 중에는 중복 전송 UX가 없어야 함

## 9. 정적 기준선

매 QA 라운드 뒤 최소 확인:

- `cd frontend && npm run lint`
- `cd frontend && npm run build`

현재 관찰:

- build는 통과하지만 번들 크기 경고가 있음
- 이는 즉시 기능 실패가 아니라 후속 성능 개선 후보로 기록
