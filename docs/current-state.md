# 현재 상태

- 현재는 운영 전환 단계가 아니라 로컬 기능/구조 검증 단계입니다.
- 운영 서버는 아직 없습니다.
- 프론트 연동 전까지는 백엔드, 문서, 로컬 smoke 기준으로 검증합니다.
- 지금 우선순위는 기능 검증, 구조 검증, 수정, 최적화/보안, 프론트 연동 검증 순서입니다.
- 운영/배포 관련 작업은 마지막 단계에서만 다룹니다.
