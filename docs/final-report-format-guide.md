# 결과보고서 글꼴 및 글자 크기 적용안

이 문서는 결과보고서 HWP 편집 시 적용할 글꼴, 글자 크기, 굵기 기준을 정리한다. 학교 또는 학과 지정 양식이 있으면 그 양식을 최우선으로 적용한다.

## 공통 원칙

- 본문은 굵게 적용하지 않는다.
- 제목, 절 제목, 소절 제목만 굵게 적용해 계층을 구분한다.
- 제목과 본문은 최소 2pt 이상 차이를 둔다.
- 표 제목과 그림 제목은 본문보다 작게 두고, 출처는 캡션보다 더 작게 둔다.
- 본문 강조가 필요하면 굵게 대신 문단 구성, 표, 번호 목록으로 처리한다.
- 한 문서 안에서는 같은 계층의 제목 크기와 글꼴을 끝까지 동일하게 유지한다.

## 적용안 A: 제출용 기본안

가장 무난한 제출용 안이다. HWP 기본 환경과 호환성이 좋고, 제목과 본문 계층 차이가 명확하다.

| 구분 | 글꼴 | 크기 | 굵기 | 정렬 |
|------|------|------|------|------|
| 문서 제목 | 함초롬돋움 또는 맑은 고딕 | 20pt | 굵게 | 가운데 |
| 장 제목 | 함초롬돋움 또는 맑은 고딕 | 16pt | 굵게 | 왼쪽 |
| 절 제목 | 함초롬돋움 또는 맑은 고딕 | 14pt | 굵게 | 왼쪽 |
| 소절 제목 | 함초롬돋움 또는 맑은 고딕 | 12pt | 굵게 | 왼쪽 |
| 본문 | 함초롬바탕 또는 휴먼명조 | 10.5pt | 보통 | 양쪽 정렬 |
| 표 내용 | 함초롬바탕 또는 휴먼명조 | 9.5pt | 보통 | 가운데 또는 왼쪽 |
| 표/그림 제목 | 함초롬바탕 또는 휴먼명조 | 9.5pt | 보통 | 가운데 |
| 출처 | 함초롬바탕 또는 휴먼명조 | 9pt | 보통 | 가운데 또는 왼쪽 |

권장 문단 설정은 본문 줄 간격 160%, 문단 위/아래 0pt, 첫 줄 들여쓰기 10pt이다.

## 적용안 B: 보수적 학술형

학교 양식이 작고 빽빽한 문서를 선호할 때 사용할 수 있다.

| 구분 | 글꼴 | 크기 | 굵기 |
|------|------|------|------|
| 장 제목 | 휴먼명조 또는 함초롬바탕 | 15pt | 굵게 |
| 절 제목 | 휴먼명조 또는 함초롬바탕 | 13pt | 굵게 |
| 소절 제목 | 휴먼명조 또는 함초롬바탕 | 11pt | 굵게 |
| 본문 | 휴먼명조 또는 함초롬바탕 | 10pt | 보통 |
| 표/그림 제목 | 휴먼명조 또는 함초롬바탕 | 9pt | 보통 |
| 출처 | 휴먼명조 또는 함초롬바탕 | 8.5pt | 보통 |

## 적용안 C: 가독성형

분량이 너무 많지 않고 화면 검토와 발표 자료 변환까지 고려할 때 사용할 수 있다.

| 구분 | 글꼴 | 크기 | 굵기 |
|------|------|------|------|
| 장 제목 | 맑은 고딕 | 17pt | 굵게 |
| 절 제목 | 맑은 고딕 | 15pt | 굵게 |
| 소절 제목 | 맑은 고딕 | 12pt | 굵게 |
| 본문 | 나눔명조 또는 함초롬바탕 | 11pt | 보통 |
| 표/그림 제목 | 나눔명조 또는 함초롬바탕 | 9.5pt | 보통 |
| 출처 | 나눔명조 또는 함초롬바탕 | 9pt | 보통 |

## 추천 적용 순서

1. 학교 양식이 없으면 적용안 A를 기본으로 사용한다.
2. HWP에서 `문서 제목`, `장 제목`, `절 제목`, `소절 제목`, `본문`, `표 내용`, `표/그림 제목`, `출처` 스타일을 먼저 만든다.
3. 기존 본문에 적용된 굵게를 해제하고, 제목 계층에만 굵게를 적용한다.
4. 표와 그림에는 반드시 번호, 제목, 출처를 함께 붙인다.
5. 전체 문서를 마지막으로 훑으면서 같은 계층 제목의 크기와 굵기가 섞이지 않았는지 확인한다.
