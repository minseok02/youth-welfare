# 졸업작품 결과보고서 개정 목차 및 반영 기준

이 문서는 청년 복지 통합 플랫폼 결과보고서의 개정 기준을 고정하기 위한 작업 문서이다.
현재 저장소에는 결과보고서 원본 파일이 없으므로, 사용자가 제공한 초안을 기준으로 목차와 보강 방향을 먼저 정리한다.

## 작성 기준

- 결과보고서의 중심은 필요성보다 실제 구현 결과, 화면, API 사용, 검증 결과에 둔다.
- 코드와 운영 문서에 근거가 있는 기능만 기재한다.
- AI 기능은 과장하지 않고, 룰 기반 후보 선별과 OpenAI API 기반 보조 평가 및 추천 사유 생성으로 설명한다.
- 공공데이터 API 출처, 사용 목적, 활용 데이터, 구현 위치를 별도 표로 정리한다.
- 논문은 분량 보강이 아니라 설계 선택의 근거로 사용한다.
- 화면 이미지는 사용자 이용 흐름과 관리자 운영 흐름의 증거로 배치한다.
- 운영 검증 내용은 내부 로그를 길게 나열하지 않고, 테스트 및 smoke test 결과로 요약한다.

## 개정 목차

### 제 1 장 서론

#### 제 1 절 프로젝트 필요성 및 배경

- 청년 복지 정책 정보의 분산 문제
- 자격 조건, 신청 기간, 제출 서류 확인 부담
- 정책 탐색 비용과 신청 기회 상실 문제
- 통합 검색, 개인화 추천, 상담형 보조 기능의 필요성

#### 제 2 절 관련 기술 및 선행연구

1. 공공데이터 통합 및 정책 데이터 정규화
2. 개인화 추천 시스템
3. 하이브리드 추천 시스템
4. 설명 가능한 추천
5. RAG 및 LLM 기반 정책 상담 기술
6. LLM 응답 한계와 보조적 활용 필요성

#### 제 3 절 프로젝트 목적 및 범위

1. 청년 복지 정책 통합 검색 제공

3. 추천 사유 제공을 통한 설명 가능성 확보
4. 챗봇과 알림을 통한 정책 활용 흐름 지원
